Install CrossX

Reading-first firmware built on CrossPoint Reader, with opt-in sync from the CrossX app. Connect your reader over USB and install it from this page.

Open this page in Chrome or Edge on a computer to install over USB. This browser cannot talk to USB serial devices. You can still read the steps below.

  1. 1 Your reader

    X4 Pro support is planned. CrossX has only been prepared for the original X4.

  2. 2 Firmware

    Checking the latest build…

    Advanced: install a .bin from your computer

  3. 3 Connect and install

    1. Connect the X4 to this computer with a USB cable that carries data.
    2. Select Install, pick the reader in the browser's device list, then select Connect.
    3. Keep the cable connected until the install finishes. It takes about two minutes.
    My reader isn't listed

    Use a data cable (many charging cables are power only), try another USB port, and close other flashing tools or serial monitors.

    Some X4 units ship with USB flashing locked. If yours never appears, use CrossPoint's unlock and install options and read Fix a bricked Xteink.

    Recovery
    
        
    Every install keeps the previous firmware in the other app slot. These tools talk to the same USB connection.
    
        
    
          
    
            
    Roll back
    
            
    Boot the firmware that ran before the last install. Takes a few seconds; nothing is downloaded.
    
            
          
    
          
    
            
    Back up flash
    
            
    Save all 16 MB of the reader's flash, including the stock firmware, before your first install. Takes about 25 minutes.
    
            
          
    
          
    
            
    Restore a backup
    
            
    Write a 16 MB backup made here back to the reader. This replaces everything on flash, including settings.
