CrossX Firmware installer

Flash the original XTEINK X4 from your browser. No toolchain needed.

Loading build information…

Pre-alpha firmware. Read this first. CrossX has not been validated on hardware yet. Some X4 units are USB-locked and cannot be flashed over USB; if the browser does not show your device in the port picker, stop and read Flashing and recovery before trying anything else. Install plain CrossPoint on a unit before installing CrossX; if CrossPoint cannot be installed, CrossX cannot either.

What you need

  • A desktop browser with Web Serial: Chrome or Edge (Safari and Firefox do not work).
  • A USB-C data cable (some charge-only cables will not enumerate).
  • The X4 powered on and awake. Books and reading progress stay on the SD card and are not touched.

Install

  1. Connect the X4 to your computer.
  2. Click a button below and pick the X4's serial port. On most systems it appears as USB JTAG/serial debug unit.
  3. Choose Install. When asked, keep erase device off unless you want a factory-clean device (erasing removes Wi-Fi credentials and CrossX pairing, not the SD card).
  4. Wait for “Installation complete”, then unplug. The device restarts on its own.

CrossX Firmware

The crossx_x4 build from the latest main: CrossPoint reader plus the CrossX sync foundation.

This browser has no Web Serial. Use Chrome or Edge on a desktop computer. Web Serial needs a secure (https) page.

Plain CrossPoint (recovery)

The upstream CrossPoint default build from the same commit, for going back to a known-good reader.

This browser has no Web Serial. Use Chrome or Edge on a desktop computer. Web Serial needs a secure (https) page.

Trouble?

  • No device in the port picker: try another cable or USB port, wake the device, close other apps using the serial port (PlatformIO monitor, Arduino IDE). If it still does not appear, the unit may be USB-locked.
  • Install fails midway: unplug, replug, and try again. The image is written as one factory image (bootloader, partition table, app), so a retry starts clean.
  • Device does not boot afterwards: follow Fix a bricked Xteink.
